# Third-party notices

MBJFW currently has no third-party Swift Package dependencies. The app uses Swift, SwiftUI, AppKit, POSIX shared memory, and native macOS system frameworks.

The first-run setup downloads these separately from their upstream publishers:

- Eclipse Temurin Java runtime from Adoptium.
- Android command-line tools, emulator, platform tools, and Android 15 Google APIs ARM64 system image from Google.

Those runtime components are not included in the MBJFW app or installer. Each component remains subject to its own upstream license and terms, which are accepted or displayed by its publisher and should be retained with the downloaded component. MBJFW does not redistribute those SDK packages or the Android image.

Minecraft Bedrock APKs are selected and imported by the user. They are not included with MBJFW. Minecraft, Mojang, and Microsoft marks and game content belong to their respective owners; MBJFW is an independent launcher project.

No source license for MBJFW is declared in this repository. Ask the project owner before reusing or redistributing MBJFW source, artwork, or binaries.
